# iPhone 真机验证步骤（约 5 分钟）

网址：https://rz2fh2jmft-a11y.github.io/pregnancy-checkin/

1. **添加到主屏幕**：用 Safari 打开网址，先确认今日页顶部有“添加到主屏幕后使用”的提示 → 点底部「分享」→「添加到主屏幕」→「添加」。📸 截图存为 real-1-safari.png
2. **从桌面打开**：点桌面上的「孕期打卡」图标。应全屏打开，顶部提示消失，弹出 3 步使用引导。走完引导，添加 1 种补剂（比如“DHA”，剂量随便填），打一次卡。📸 real-2-standalone.png
3. **查看存储状态**：进入「备份」页，记下“持久存储：已开启/未开启”这一行。📸 real-3-persist.png
4. **离线冷启动**：打开飞行模式（Wi-Fi 也关掉）→ 上滑彻底关掉这个 App → 再从桌面图标打开。5 个标签页（今日/历史/体重/补剂/备份）逐个点开都应正常；再打一次卡、记一条体重。📸 real-4-offline.png
5. **重启验证**：关掉飞行模式，把手机关机重启 → 打开图标，第 2、4 步的打卡和体重都还在。📸 real-5-reboot.png
6. **安全区**：页面标题没有被灵动岛挡住，底部标签栏没有被横条挡住；打卡后底部“已记录 · 撤销”提示条在标签栏上方。

有任何一步不符合，把截图发给我就行。
